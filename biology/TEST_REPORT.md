## 四、測試中發現並已修正的問題
1. 麵包屑被插進兩欄格線，把主內容擠到側欄下方 → 改成麵包屑和主內容包在同一欄
2. 切換設定時觸發的重新繪製比新頁面晚完成，把新頁面蓋掉（競態）→ 每次換頁使用獨立容器
3. 作答回饋要等資料庫寫入完才出現 → 先顯示回饋，紀錄在背景依序寫入
4. 同義詞（Krebs／citric acid／TCA cycle 等）可能變成「兩個正確答案」→ 同義詞組與相關詞不再當干擾選項
5. 拼字題的中文解釋會出現英文拼法 → 遮蔽英文字
6. 手機底部選單缺少練習、測驗、備份等入口 → 新增「☰ 更多」
7. 全螢幕請求在部分環境會一直懸置 → 3 秒逾時就提示；對話框開啟時，提示訊息改顯示在對話框內
8. 心智圖單元框重疊 → 改成單元平均分布在外圈
9. 語音清單晚載入時，單字頁的語音說明不會更新 → 監聽 `voiceschanged` 事件
10. 單元說明只有中文 → 補上英文的單元說明、學習目標與先備知識
